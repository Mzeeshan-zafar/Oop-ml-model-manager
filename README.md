# OOP ML Model Manager

A Python project demonstrating Object-Oriented Programming (OOP) concepts applied to Machine Learning models.

## 🎯 Purpose

This project shows how to organize ML models using OOP principles:
- **Classes & Objects** — Each model is a class
- **Inheritance** — Child classes inherit from `MachineLearningModel`
- **Polymorphism** — Same method (`train()`) behaves differently per model
- **Encapsulation** — Private variables with getters/setters
- **Magic Methods** — `__str__` for readable output
